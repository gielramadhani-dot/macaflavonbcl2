# Macaflavone GNN-Augmented Docking Supplementary Package

This repository package contains GitHub-ready supplementary materials for the manuscript:

**Deep GNN-Augmented Ensemble Docking, Molecular Explainability, and 3D Protein-Ligand Interaction Graph Analysis Prioritize Macaflavone I Across EGFR, HER2, and VEGFR2**

## Contents

- `docs/` — Supplementary Information DOCX and article layout draft.
- `figures/main/` — Main manuscript Figure 1-Figure 7 image files.
- `figures/supplementary/` — Supplementary Figure S1-S8 image files.
- `tables/main/` — Main Table 1-Table 7 as CSV.
- `tables/supplementary/` — Supplementary Table S1-S20 as CSV.
- `source_maps/` — Mapping between manuscript tables/figures and staged Google Drive source outputs.
- `metadata/` — Figure manifest, data dictionary, and claim-control notes.

## Reproducibility note

The package is designed as a manuscript-supplementary and GitHub release scaffold. Full raw high-volume files, including all docking poses, all GNN predictions, full 3D graph node/edge tables, and interactive HTML viewers, should be added from the original staged project folders before public release.

## Interpretation note

The results should be interpreted as computational prioritization. They do not constitute experimental validation of kinase inhibition or biological activity.
