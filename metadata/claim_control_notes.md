# Claim-control notes for manuscript and GitHub release

Acceptable phrasing:
- Maca-1 was computationally prioritized over Maca-2 across integrated docking, GNN, explainability, and 3D interaction graph evidence.
- The GNN layer provides target-conditioned prioritization signals.
- The 3D graph layer provides pose-geometry consistency evidence.
- Experimental validation is required.

Avoid:
- Maca-1 is a validated inhibitor.
- GNN proves binding affinity.
- Docking/GNN confirms biological activity.
- The 3D graph validates kinase inhibition.

Provenance note:
- Tables in this GitHub package are manuscript-level summaries derived from the staged Google Drive outputs.
- Large full tables should be uploaded from the original Stage 3-6E CSV/XLSX files when creating the final repository release.
